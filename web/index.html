SYSMOD Viewer

Shows a SYSMOD project of a SysML v2 model the way the method structures it: the SYSMOD Atlas, the problem statement, the system idea and its objectives, stakeholders, needs, system requirements, system use cases and the system context of every architecture. It reads the model with the SysML v2 API (OMG Systems Modeling API). A single page, no server of its own: everything runs in your browser.

Open a model

The address of a SysML v2 API server, e.g. the API services of the SysML v2 Pilot Implementation or Open-MBEE Flexo. Opened directly, the page can only read servers that allow requests from it (CORS); run python web/serve.py to reach any server through its local relay.

A .json file with the elements of a commit, as GET …/commits/{commit}/elements of the SysML v2 API returns them. To view .sysml files, use mbse4u.com/tools/sysmod-viewer, which reads them with a SysML v2 engine in the browser.

Good to know

  • Run it: python web/serve.py, then open http://localhost:8080/. The script needs only Python 3, no packages. Browsers do not run the page from a file:// address.
  • CORS and http: a page can only read servers that allow requests from it. serve.py also relays the requests (read-only) to the servers in ALLOWED_SYSML_SERVER_ORIGINS (default http://localhost:9000), including plain http:// ones and servers without CORS.
  • Token: optional, passed on as header Authorization; it stays in the page and is never stored. The page address records server, project and commit (not the token).
  • SYSMOD v5: the project is an occurrence def with #project or a specialization of SYSMOD::Project; the SYSMOD library must be in the same project.
  • Read-only. Editing, the AI suggestions and the creation wizard are in the Flask server of this repository (sysmod_api_server.py).
